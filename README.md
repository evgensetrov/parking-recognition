# Подсчёт машин на парковке (раз в минуту)

Каждую минуту: снимок с камеры → подсчёт машин нейросетью → файлы в `./data`. Время везде московское.

## 1. Запуск

```bash
cp .env.example .env          # впишите адрес, порт, логин и пароль камеры, PUID/PGID (id -u; id -g)
mkdir -p data models          # папки создаём сами, чтобы права были ваши
cp /путь/к/best.pt models/best.pt
docker compose up -d --build
docker compose logs -f        # раз в минуту: «12:05: машин 118 (неуверенных 9, всего рамок 131)»
```

`mask.png` лежит рядом с `docker-compose.yml` и монтируется в контейнер. Порог уверенности (`CONF=0.3`),
интервал и прочие параметры задаются в `docker-compose.yml` (см. `monitor.py`, класс `Config`).
Остановить: `docker compose down`. Состояние: `docker compose ps` (healthcheck «unhealthy», если 5 минут нет ни одного удачного кадра).

## 2. Что появляется в `./data`

```
data/2026/11/12/14/
    14_05_camera.jpeg        снимок с камеры как получен
    14_05_result.jpeg        повёрнутый кадр с рамками и числом машин (для оценки глазами)
    14_05_labels.txt         рамки засчитанных машин, формат YOLO (для CVAT)
    14_05_detections.json    все рамки с уверенностью, число машин, параметры, хеш маски
    count.csv                time,count  (одна строка на минуту, время в ISO с +03:00)
```

Цвета рамок на `*_result.jpeg`: зелёная — машина засчитана, жёлтая — внутри области, но уверенность ниже порога
(кандидат), красная — вне области. Если нужен и повёрнутый кадр без рамок, поставьте `SAVE_PREP: "1"`;
обычно он не нужен, его можно пересоздать из `camera.jpeg`.

Место: ориентировочно 1–1,5 ГБ в сутки (снимок 4K ≈ 0,5–1 МБ плюс картинка результата), это оценка, а не замер.
Старые снимки можно чистить, но тогда эти кадры нельзя будет взять на доразметку: `count.csv` весит мало, его оставляйте.

## 3. Доразметка в CVAT

Предразметку делает сама сеть, поэтому править придётся только ошибки.

1. **Отобрать кадры** (на компьютере с Python, нужны `opencv-python` и `numpy`; в папке проекта):
   ```bash
   python export_for_cvat.py --since 2026-11-12 --until 2026-11-14 -n 40
   ```
   Берутся кадры, на которых сеть наименее уверена (`--strategy uncertain`, по умолчанию), не чаще чем раз в 20 минут.
   Другие режимы: `--strategy uniform` (равномерно по времени), `--strategy random`; `--hours 7-22` — только дневные часы.
   Уже выгруженные кадры повторно не берутся (список в `data/exported_frames.txt`).
   Результат: папка `cvat_pack_<дата>/` с `cvat_images.zip` и `cvat_import.zip`.
2. **Создать задачу в CVAT**: Tasks → «+» → метка `car` (тип Rectangle) → загрузить `cvat_images.zip`.
3. **Загрузить предразметку**: меню задачи (⋮) → Upload annotations → формат «YOLO 1.1» → `cvat_import.zip`.
4. **Поправить**: добавить пропущенные машины, удалить лишние рамки. Особое внимание тёмным и дальним машинам и кромке области.
5. **Экспортировать**: ⋮ → Export task dataset → «CVAT for images 1.1» (на бесплатном тарифе без картинок, это нормально). Распакуйте, нужен `annotations.xml`.
6. **Влить в общий набор** (папка `cvat_export/` с `annotations.xml` и `images/`; положите туда ваш текущий набор из 42 кадров):
   ```bash
   python merge_cvat_exports.py --new-xml путь/к/annotations.xml --new-images cvat_pack_<дата>/images
   ```

## 4. Дообучение

1. Заархивируйте `cvat_export/` и загрузите в Colab вместе с `2_make_dataset.py` и `3_train.py` (GPU включить).
2. В Colab: `!unzip -q cvat_export.zip -d cvat_export`, затем `!python 2_make_dataset.py` и `!python 3_train.py`.
   Обучать проще и надёжнее заново на всём объединённом наборе, стартуя с обычных весов (`yolo11l.pt`), чем дообучать старый `best.pt`.
3. Вес новой модели: `runs/.../weights/best.pt` (в логе обучения указан точный путь).
4. **Сравните со старой моделью** на 5–10 кадрах, где вы пересчитали машины вручную. Одних метрик val недостаточно:
   при пересборке набора разбиение train/val меняется, и цифры нельзя сравнивать напрямую.
5. Подмена модели: положите новый файл в `models/best.pt` (старый сохраните), затем `docker compose restart`.
   Порог `CONF` при необходимости подберите заново и поменяйте в `docker-compose.yml`.

## 5. Важно

- **Не меняйте `mask.png` и угол поворота**, пока не готовы переразметить набор: рамки привязаны к геометрии повёрнутого кадра.
  В `detections.json` пишется хеш маски; `export_for_cvat.py` пропускает кадры, обработанные другой маской.
- Камера должна отдавать основной поток в том же размере, что и размер `mask.png` (сейчас 3840×2160), иначе кадр отклоняется с ошибкой в логе.
- Адрес и пароль камеры хранятся только в `.env`, в код они не попадают.
