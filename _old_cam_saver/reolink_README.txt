Reolink-камера 93.100.247.132:9000 — инструменты подключения (протокол Baichuan)

ЧТО ЭТО
  Рабочие скрипты подключения к камере Reolink через фирменный бинарный
  протокол Baichuan (порт 9000). Учётные данные и адрес уже вписаны.

ФАЙЛЫ
  ConnectionLayer.py — библиотека протокола (логин, шифрование BC-XOR/AES)
  bc_final.py        — снимок JPEG с камеры (сохраняет reolink_snapshot.jpg)
  bc_video.py        — захват живого видео H.265 (сохраняет /tmp/video.h265)

ТРЕБОВАНИЯ
  Python 3.8+ и пакет pycryptodome:
      pip install pycryptodome

ЗАПУСК
  python3 bc_final.py    -> снимок 4K с основного потока
  python3 bc_video.py    -> ~15 секунд видео с основного потока

КАК ЭТО РАБОТАЕТ (кратко)
  1. TCP-соединение с портом 9000
  2. GetNonce -> камера отдаёт nonce, выбирает шифрование (AES)
  3. Логин: MD5(логин+nonce) и MD5(пароль+nonce), обрезанные до 31 символа
  4. Все дальнейшие сообщения шифруются AES-128-CFB,
     ключ = первые 16 символов ВЕРХНЕГО hex MD5(nonce + "-" + пароль)
  5. Снимок: сообщение 109 (Snap); видео: сообщение 3 (Preview)

ПАРАМЕТРЫ КАМЕРЫ (получены при подключении)
  Тип: IPC, 1 канал, звук есть, SD-карта есть
  Основной поток:  3840x2160 H.265, 25 к/с, ~6 Мбит/с
  Доп. режимы:     2560x1440, 2304x1296
  Субпоток:        640x360, 10 к/с, 256 кбит/с
